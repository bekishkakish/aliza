# Ресурсы и лицензии

Автор и куратор учебного проекта — Ализа. Фамилия, учебное заведение и группа не добавлялись.

## Фотографии и звук

Все финальные фотографии созданы специально для проекта с помощью встроенного Imagegen. Кадры из фильмов, случайные стоковые фотографии, водяные знаки и внешние музыкальные записи не использовались. Генерация сама по себе не является утверждением об исключительных авторских правах на результат.

Портретные материалы Ализы созданы по предоставленным пользователем референсам с указанным в задании согласием. Исходные личные фотографии не включены в проект. Подготовленные портреты требуют окончательной субъективной оценки узнаваемости автором перед её решением о публикации.

| Файлы в `public/media`                                                       | Содержание                                                                |
| ---------------------------------------------------------------------------- | ------------------------------------------------------------------------- |
| `theatre*`                                                                   | Театральная сцена, луч света и анонимный силуэт.                          |
| `medium*`, `close*`                                                          | Анонимная актриса в театральном пространстве, разные планы. Это не Ализа. |
| `detail*`                                                                    | Деталь руки и чёрной ткани.                                               |
| `room*`, `street*`, `corridor*`                                              | Комната с окном, улица после дождя, закулисный коридор.                   |
| `aliza-portrait*`, `aliza-fear*`, `aliza-joy*`, `aliza-love*`, `aliza-hope*` | Постановочные портретные этюды Ализы с актуальными светлыми волосами.     |
| `aliza-credits*`                                                             | Монохромный производный вариант `aliza-portrait`.                         |

`public/social.jpg` — производная обложка из `theatre` с типографикой проекта. `public/favicon.svg` — собственная векторная эмблема. Плёночная фактура создаётся SVG-фильтром. Звуковая атмосфера — собственный синтез трёх синусоидальных осцилляторов через Web Audio, без музыкальных файлов.
