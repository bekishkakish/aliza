# Готовность к GitHub Pages

11 ноября 2026 года. Репозиторий: **[bekishkakish/aliza](https://github.com/bekishkakish/aliza)**. Базовый путь: **`/aliza/`**. Адрес сайта: **https://bekishkakish.github.io/aliza/**. Изменены только пути ресурсов, конфигурация сборки/проверок, workflow, исключения Git и документация. Дизайн, анимации, изображения и поведение лаборатории сохранены.

## Выполнено

- В `vite.config.ts` установлен `base: '/aliza/'`.
- Фотографии, responsive srcset, миниатюры и изображения Canvas используют `import.meta.env.BASE_URL`. HTML-обложка, favicon и preload используют `%BASE_URL%`.
- Собранные CSS/JavaScript и локальные шрифты имеют корректные адреса внутри каталога проекта.
- Добавлен `.github/workflows/deploy.yml`: Node.js 24, установка из lockfile, build/TypeScript, Chromium и Playwright, передача только `dist`, отдельный deploy job с разрешениями Pages/OIDC. Действия закреплены на SHA из официального руководства Vite.
- Добавлен строгий статический preview без SPA-fallback. Он возвращает 404 для отсутствующих файлов и обращений к `/media/...` вне `/aliza/`.
- Главы используют якоря, формат сцены сохраняет каталог при создании ссылки и восстанавливает настройки после прямого открытия и перезагрузки.

## Приватные материалы

В `.gitignore` исключены `node_modules`, `dist`, `.env*`, `.asset-sources`, приватные папки, исходные фотографии с предоставленными именами, вложения, локальные данные Codex, ключи и результаты тестов. Исходные личные фотографии находились вне проекта и не копировались в публичную сборку. Дополнительно проверено отсутствие приватных путей в `dist`.

Перед коммитом проверяется весь индекс Git: исходные личные фотографии, локальные диагностики, рабочие PNG, приватные папки и секреты не должны присутствовать. Публикуются исходный код, тесты и инструменты сборки, документация, лицензии и подготовленные ресурсы из `public/`.

## Публикация

Используется существующий репозиторий. Источник Pages — **Settings → Pages → Source → GitHub Actions**, рабочая ветка — `main`. При каждом push workflow выполняет сборку и проверки, затем публикует `dist`. Команды приведены в [README](../README.md#публикация-на-github-pages).

Актуальный статус удалённой сборки и публикации находится во [вкладке Actions](https://github.com/bekishkakish/aliza/actions). Успех локальных тестов сам по себе не подтверждает публикацию: её подтверждают успешный deploy job и доступность публичного сайта.
