# Проверка мобильной адаптации

11 ноября 2026 года. Существующий проект и путь GitHub Pages `/aliza/` сохранены.

## Исправления

- У заголовков и подписей была разная граница мобильной компоновки: вертикальное расположение включалось только до 540 px, а боковая подпись сохраняла фиксированную ширину. До 767 px теперь используется отдельная вертикальная композиция, гибкие размеры заголовков и подпись с SVG в собственной колонке. Дочерние элементы flex/grid могут сжиматься через `min-width: 0`.
- Символ `✳` воспроизвёлся в WebKit как зелёный emoji. Он заменён оригинальной восьмилучевой SVG-звездой без зависимости от системного emoji-шрифта.
- Убрано `main { overflow: clip }`: ошибки больше не маскируются общим обрезанием страницы. Локальное кадрирование фотографий и сцены сохранено.
- В узкой пятиколоночной строке эмоций надпись «Одиночество» выходила за свою кнопку. На телефоне переключатели образуют два ряда с более крупными подписями и удобными областями касания.
- В крайних положениях сравнения света круглый маркер обрезался краем сцены. Линия по-прежнему проходит весь диапазон 0–100%, а маркер остаётся полностью видимым.
- Подписи монитора лаборатории переносятся, кнопка полноэкранного просмотра имеет область касания 44 × 44 px. Поля ссылки и выбора света используют 16 px, чтобы Safari не увеличивал страницу при фокусировке.
- Меню больше не расширяет свои строки отрицательными отступами. Автоматическое увеличение текста WebKit нормализовано через `text-size-adjust: 100%`; масштабирование страницы пользователем разрешено.

## Проверки

- Production build и TypeScript: успешно.
- Полный Playwright-прогон в Chromium/Edge: **41 / 41**.
- Дополнительный прогон мобильной адаптации в WebKit: **11 / 11**.
- Проверены все шесть глав на ширинах **320, 360, 375, 390, 393, 414, 430, 768, 1024, 1440 px** в обоих движках.
- Дополнительно проверены переходы через границы 540/541, 767/768, 800/801 px, ширины 600 и 667 px и увеличение базового размера текста до 125%.
- Проверяется строгое `document.documentElement.scrollWidth <= window.innerWidth`, реальные `getBoundingClientRect()`, прямоугольники отдельных строк текста через `Range.getClientRects()` и переполнение содержимого элементов.
- Единственное исключение для выходящих за viewport карточек — намеренная нативная горизонтальная прокрутка выбора окружения. Её контейнер обязан помещаться в экран, а последняя карточка «Ализа» проверяется реальным касанием после прокрутки.
- Проверены раскрытое сравнение света и его крайние положения, длинные подписи лаборатории, ссылка сцены, готовый постер, полноэкранный кадр и меню. Во время матрицы не обнаружено ошибок JavaScript/консоли и ответов ресурсов HTTP 400+.
- Полный набор также проверяет PNG 1600 × 1320, восстановление сцены по ссылке, навигацию, смену изображений, пружины, reduced motion, финальные титры и автоматические WCAG A/AA проверки.

Скриншоты всех глав до/после находятся локально в игнорируемой `.asset-sources/mobile-audit/`; снимки каждого размера расширенного теста — в `test-results/`. Они не публикуются вместе с сайтом. WebKit проверен через Playwright с мобильным viewport и касаниями; это не испытание на физическом iPhone.

## Повторный запуск

```powershell
npm ci
npm run build
npm test
$env:PLAYWRIGHT_BROWSER = 'webkit'
npx playwright install webkit
npx playwright test tests/responsive.spec.ts
Remove-Item Env:PLAYWRIGHT_BROWSER
```

В GitHub Actions оба движка устанавливаются и проверяются перед передачей артефакта Pages. При ошибке любой проверки публикация не запускается.
